2.1 Pendahuluan

Program Studi: Data Science Konteks Sesi: Pertemuan 2 – Jenis Data dan Skala Pengukuran Seorang analis menerima data survei pelanggan dan langsung menghitung “rata-rata jenis kelamin = 1,46” serta “rata-rata kepuasan = 3,2”. Angka pertama jelas tidak bermakna; angka kedua masih diperdebatkan. Mengapa? Karena jenis data dan skala pengukurannya menentukan operasi apa yang sah. Menghitung sesuatu hanya karena R bisa menghitungnya adalah sumber kesalahan analisis yang paling umum.

Pada Pertemuan 1 kita membedakan variabel numerik dan kategorik. Pertemuan ini memperhalus klasifikasi tersebut menjadi kerangka yang dipakai sepanjang semester: jenis data, sumber data, skala pengukuran, dan struktur dataset.

2.1.1 Tujuan Pembelajaran

Setelah menyelesaikan praktikum ini, mahasiswa mampu:

  1. Membedakan data kualitatif dan kuantitatif, serta data kuantitatif diskrit dan kontinu.

  2. Membedakan data primer dan sekunder beserta kelebihan, kelemahan, dan pentingnya metadata.

  3. Menentukan skala pengukuran (nominal, ordinal, interval, rasio) dan operasi statistik yang sah untuk tiap skala.

  4. Merepresentasikan setiap skala dengan tipe data yang tepat di R (character, factor, ordered, integer, numeric).

  5. Menjelaskan struktur dataset: observasi, variabel, feature, dan target, termasuk format tidy, wide, dan long.

2.2.2 Kuantitatif Diskrit vs Kontinu

Jenis Ciri Contoh Cara memperoleh
Diskrit Nilai terhitung (biasanya bilangan bulat); ada “celah” di antara nilai yang mungkin Jumlah anak, jumlah transaksi, jumlah mahasiswa yang hadir Menghitung (counting)
Kontinu Nilai dapat berada di mana saja dalam suatu rentang, dibatasi hanya oleh ketelitian alat Tinggi badan, waktu tempuh, suhu, kadar TSS air Mengukur (measuring)

Pertanyaan praktis untuk membedakan: “Apakah nilai 2,5 masuk akal?” Jumlah anak 2,5 tidak mungkin (diskrit), tetapi waktu tempuh 2,5 jam masuk akal (kontinu).

jumlah_anak <- c(0L, 2L, 1L, 3L, 2L) # L -> integer (bilangan bulat)
waktu_jam <- c(1.25, 2.5, 0.75, 3.1, 1.8) # numeric (bilangan desimal)
class(jumlah_anak); class(waktu_jam)

semua_bulat <- function(x) all(x == round(x))
c(jumlah_anak = semua_bulat(jumlah_anak), waktu_jam = semua_bulat(waktu_jam))
jumlah_anak   waktu_jam 
       TRUE       FALSE
Pembulatan tidak mengubah jenis data. Usia yang dicatat “21 tahun” tetap kon- tinu, karena usia sebenarnya terus bertambah; bilangan bulat hanya akibat cara pen- catatan. Sebaliknya, uang (Rp) secara teknis diskrit (satuan terkecil rupiah), tetapi karena rentangnya sangat besar, dalam praktik diperlakukan sebagai kontinu.

Perbedaan diskrit-kontinu memengaruhi grafik yang tepat (Pertemuan 4): data diskrit dengan sedikit nilai cocok dengan diagram batang per nilai, data kontinu dengan histogram.

2.3 Sumber Data

2.3.1 Data Primer vs Sekunder

Aspek Data Primer Data Sekunder
Definisi Dikumpulkan sendiri oleh peneliti untuk tujuan penelitiannya Dikumpulkan pihak lain untuk tujuan lain, lalu dipakai ulang
Contoh Kuesioner kepuasan yang Anda sebar; pengukuran sampel air di lapangan Data BPS, laporan keuangan emiten, dataset Kaggle, log transaksi perusahaan
Kelebihan Sesuai kebutuhan; definisi variabel dan metode diketahui persis Murah, cepat, sering berukuran besar dan mencakup periode panjang
Kelemahan Mahal, lama, butuh desain yang cermat Definisi variabel mungkin tidak sesuai; kualitas dan cara pengumpulan harus diverifikasi

Dalam data science, sebagian besar pekerjaan memakai data sekunder (misalnya data transaksi yang tercatat otomatis). Karena kita tidak mengumpulkannya sendiri, metadata – keterangan tentang arti tiap variabel, satuan, kode, periode, dan cara pengumpulan – menjadi sangat penting.

2.5 Skala Pengukuran

Skala pengukuran (tipologi Stevens) mengelompokkan data menurut sifat-sifat matematis yang dimiliki nilainya. Setiap tingkat memiliki semua sifat tingkat sebelumnya ditambah satu sifat baru.

Skala Sifat baru Arti Contoh
Nominal Identitas Nilai hanya membedakan kategori Golongan darah, metode pembayaran, jenis kelamin
Ordinal + Urutan Kategori dapat diurutkan, tetapi jarak antarkategori tidak pasti sama Tingkat kepuasan, pendidikan terakhir, peringkat lomba
Interval + Jarak sama Selisih antarnilai bermakna dan setara, tetapi nol tidak mutlak Suhu °C/°F, tahun kalender, skor IQ
Rasio + Nol mutlak Nol berarti “tidak ada sama sekali”, sehingga perbandingan (rasio) bermakna Berat, pendapatan, jumlah transaksi, suhu Kelvin

2.5.1 Operasi yang Sah untuk Tiap Skala

Operasi / Statistik Nominal Ordinal Interval Rasio
Frekuensi, modus Ya Ya Ya Ya
Mengurutkan, median, persentil Tidak Ya Ya Ya
Penjumlahan/selisih, mean, simpangan baku Tidak Diperdebatkan Ya Ya
Perbandingan “dua kali lipat”, koefisien variasi Tidak Tidak Tidak Ya

Tabel ini akan terus kita pakai: pada Pertemuan 5 untuk memilih ukuran pemusatan, dan pada paruh kedua semester untuk memilih uji statistik.

2.5.2 Nominal: Angka Hanya Sebagai Label

Jika kategori nominal dikodekan dengan angka, R akan dengan senang hati menghitung rata- ratanya – dan hasilnya tidak bermakna.

# Kode provinsi: 31 = DKI Jakarta, 32 = Jawa Barat, 33 = Jawa Tengah, 73 = Sulawesi Selatan
kode_prov <- c(32, 32, 31, 73, 33, 32, 31)
mean(kode_prov) # "rata-rata provinsi" = 36,3 -> tidak bermakna!
[1] 37.71429
# Perlakukan sebagai kategori
prov <- factor(kode_prov, levels = c(31, 32, 33, 73),

labels = c("DKI Jakarta", "Jawa Barat", "Jawa Tengah", "Sulawesi Selatan"))

table(prov)
prov
     DKI Jakarta       Jawa Barat      Jawa Tengah Sulawesi Selatan 
               2                3                1                1

Pada skala kepuasan “Sangat Tidak Puas – Tidak Puas – Netral – Puas – Sangat Puas”, kita tahu urutannya, tetapi tidak tahu apakah jarak “Netral ke Puas” sama dengan jarak “Puas ke Sangat Puas”.

survei$pendidikan <- factor(survei$pendidikan, levels = c("SMA", "D3", "S1", "S2"),

ordered = TRUE)

# Median untuk data ordinal: kategori tengah setelah diurutkan.
# Jika n genap dan dua data tengah berbeda kategori, median berada "di antara" keduanya.
median_ordinal <- function(x) {
m <- median(as.integer(x), na.rm = TRUE)
if (m == floor(m)) return(levels(x)[m])
paste("antara", levels(x)[floor(m)], "dan", levels(x)[ceiling(m)])
}
sort(as.integer(survei$kepuasan)) # posisi urutan tiap responden
[1] 1 2 3 4 4 5
median_ordinal(survei$kepuasan)
[1] "antara Netral dan Puas"

Likert: mean atau median? Skor Likert (1–5) dari satu butir pertanyaan secara ketat bersifat ordinal, sehingga median dan modus lebih tepat. Dalam praktik, jumlah atau rata-rata dari banyak butir (misalnya indeks kepuasan dari 10 pertanyaan) sering diperlakukan sebagai data interval. Apa pun pilihannya, nyatakan asumsi Anda.

2.5.4 Interval: Selisih Bermakna, Rasio Tidak

Suhu dalam °C memiliki jarak yang setara (naik dari 10 ke 20 °C sama besarnya dengan dari 20 ke 30 °C), tetapi titik 0 °C bukan “tidak ada panas” – hanya titik beku air yang dipilih secara konvensi. Akibatnya, “20 °C dua kali lebih panas dari 10 °C” adalah pernyataan keliru.

suhu_c <- c(pagi = 10, siang = 20)
suhu_f <- suhu_c * 9 / 5 + 32
suhu_k <- suhu_c + 273.15
knitr:: kable(data.frame(
Satuan = c("Celsius", "Fahrenheit", "Kelvin"),
Pagi = c(suhu_c["pagi"], suhu_f["pagi"], suhu_k["pagi"]),
Siang = c(suhu_c["siang"], suhu_f["siang"], suhu_k["siang"]),
Rasio_Siang_per_Pagi = round(c(suhu_c["siang"] / suhu_c["pagi"],
suhu_f["siang"] / suhu_f["pagi"],
suhu_k["siang"] / suhu_k["pagi"]), 3),

Selisih = c(diff(suhu_c), diff(suhu_f), diff(suhu_k))
), caption = "Suhu yang sama dalam tiga satuan")

“Rasio” suhu berubah-ubah tergantung satuan (2 kali dalam °C, 1,36 kali dalam °F, 1,035 kali dalam Kelvin) – tanda bahwa rasio pada skala interval tidak bermakna. Hanya Kelvin, yang nolnya mutlak, yang merupakan skala rasio.

2.5.5 Rasio: Semua Operasi Sah

Pada skala rasio, perbandingan tetap sama berapa pun satuannya.

berat_kg <- c(koper_A = 10, koper_B = 20)
berat_lb <- berat_kg * 2.20462
c(Rasio_kg = unname(berat_kg["koper_B"] / berat_kg["koper_A"]),
Rasio_lb = unname(berat_lb["koper_B"] / berat_lb["koper_A"]))
Rasio_kg Rasio_lb 
       2        2

Koper B benar-benar dua kali lebih berat dari koper A, dalam satuan apa pun. Karena itu koefisien variasi (Pertemuan 5) hanya sah untuk skala rasio.

2.8.5 Pertanyaan Diskusi dan Jawaban

1. Mengapa gender tidak boleh dibiarkan sebagai int? Karena angka 1 dan 2 hanya kode. Jika dibiarkan numerik, model akan menganggap “Perempuan = 2 kali Laki-laki” atau menghitung rata-rata gender (misalnya 1,5) yang tidak bermakna.

2. Bolehkah kita menyatakan “rata-rata rating layanan = 3,25”? Secara ketat tidak, karena rating_layanan adalah satu butir skala ordinal – jarak antara rating 1 ke 2 belum tentu sama dengan 4 ke 5. Laporan yang aman: median (antara 3 dan 4) dan distribusi frekuensinya. Jika mean tetap dilaporkan, nyatakan bahwa rating diasumsikan berskala interval.

3. Mengapa rasio “suhu gudang C003 dibanding C001” tidak bermakna, sementara rasio total belanja bermakna?

Suhu °C berskala interval (nol tidak mutlak), sedangkan total belanja berskala rasio (Rp 0 be- rarti tidak berbelanja sama sekali). Pelanggan C008 benar-benar berbelanja sekitar 75 kali lipat

pelanggan C005.

4. Mengapa id dikeluarkan dari feature? id unik untuk setiap pelanggan dan tidak memuat informasi perilaku. Memasukkannya dapat membuat model “menghafal” pelanggan, bukan mempelajari pola.

# (3) Kontinu (4) Diskrit

Soal C. Diberikan vektor kelas_hotel <- c(“Bintang 3”, “Bintang 5”, “Bintang 4”, “Bintang 3”, “Bintang 5”, “Bintang 3”). Ubah menjadi ordered factor, tampilkan frekuensinya sesuai urutan, lalu tentukan medianya.

kelas_hotel <- c("Bintang 3", "Bintang 5", "Bintang 4", "Bintang 3", "Bintang 5", "Bintang 3")
# Kunci jawaban:
kelas_hotel <- factor(kelas_hotel, levels = c("Bintang 3", "Bintang 4", "Bintang 5"),

ordered = TRUE)

table(kelas_hotel) # 3, 1, 2
kelas_hotel

        3         1         2

[1] "antara Bintang 3 dan Bintang 4"

Soal D. Seorang analis menyatakan: “Kota A (suhu rata-rata 30 °C) dua kali lebih panas daripada Kota B (15 °C).” Apakah pernyataan ini benar? Buktikan dengan R.

# Kunci jawaban:
c(A = 30, B = 15) + 273.15 # 303.15 K dan 288.15 K
     A      B 
303.15 288.15

2.10 Kesalahan Umum dalam Jenis Data dan Skala Pengukuran

  1. Menghitung mean dari kode kategori – misalnya “rata-rata gender = 1,46” atau “rata- rata kode provinsi”.

  2. Menganggap semua angka sebagai kuantitatif – nomor punggung, kode pos, dan NIM adalah label.

  3. Membuat pernyataan rasio pada skala interval – “20 °C dua kali lebih panas dari 10 °C”.

  4. Mengira pembulatan membuat data menjadi diskrit – usia “21 tahun” tetap kontinu.

  5. Membiarkan data ordinal sebagai teks – R mengurutkannya menurut abjad sehingga grafik dan tabel menjadi tidak logis.

  6. Memakai as.numeric() langsung pada factor berisi angka – hasilnya nomor level; gunakan as.numeric(as.character(x)).

  7. Membiarkan angka tersimpan sebagai teks (“Rp 12.500”) – perhitungan menghasilkan NA.

  8. Memakai data sekunder tanpa membaca metadata – satuan (°F vs °C) atau kode (5 = Mei)

  9. Memasukkan kolom ID sebagai feature – model menghafal, bukan belajar.

  10. Menganalisis data dalam format wide ketika sebuah variabel tersembunyi di nama kolom – ubah ke format long terlebih dahulu.

  11. Merata-ratakan satu butir Likert tanpa menyatakan asumsi – laporkan me- dian/frekuensi, atau nyatakan asumsi interval secara eksplisit.

2.13 Rangkuman dan Kesimpulan

  1. Data kualitatif berupa kategori; data kuantitatif berupa angka yang bermakna secara aritmetika. Data kuantitatif dibagi menjadi diskrit (menghitung) dan kontinu (mengukur).

  2. Data primer dikumpulkan sendiri, data sekunder dipakai ulang. Data sekunder wajib disertai metadata.

  3. Skala pengukuran – nominal, ordinal, interval, rasio – bersifat bertingkat. Makin tinggi skalanya, makin banyak operasi yang sah. Rasio “dua kali lipat” hanya sah pada skala rasio.

  4. Tipe data di R harus mencerminkan skala: factor untuk nominal, ordered untuk ordinal, numeric untuk interval/rasio. R hanya tahu tipe penyimpanan; maknanya ditentukan analis.

  5. Dataset tidy menempatkan observasi di baris dan variabel di kolom. Dalam machine learning, variabel dibagi menjadi feature dan target, dan skala target menentukan jenis tugas (klasifikasi atau regresi).

Jembatan ke sesi berikutnya: setelah memahami jenis data, Pertemuan 3 membahas bagaimana data diperoleh – metode pengumpulan data, teknik sampling probabilitas dan non-probabilitas, serta berbagai bentuk bias yang dapat merusak kesimpulan.
